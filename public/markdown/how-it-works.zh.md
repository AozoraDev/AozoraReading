# 工作原理

Aozora Reading 是一款 AI 辅助的小说阅读平台，帮助你更高效地导入、管理与阅读长篇作品。

## 1. 导入作品

在仪表盘上传 `.txt` 文件后，系统会按章节标题智能切分正文（支持 UTF-8 / GBK 编码与多种章节标题格式），并批量写入数据库。

## 2. AI 阅读辅助

阅读章节时，可配置自有 LLM API，一键生成：

- **前情回顾** — 基于上一章正文，简要回顾剧情
- **本章总结** — 提炼当前章节要点

生成结果会缓存到数据库，再次查看时无需重复调用。

## 3. 轻松阅读

书城浏览与搜索，章节间快速跳转，上下章导航，随时回到想读的位置。

## 4. 收藏作品

登录后可收藏喜欢的小说，在收藏页快速找到并继续阅读。
